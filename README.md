# Dryline-ENSO--Cyclone-variability
Scripts and data related to the generation and analysis of dryline, ENSO, and extratropical cyclone datasets for Hosek et al. (2027; in-review). This repository is for referential purposes and is not actively maintained or updated.

analysis.yaml -- the Python environment used for all /analysis scripts and building the cyclone database from CyTRACK output.
cytrack.yaml -- the Python environment used for CyTRACK.

FrontFinder AI (Justin et al. 2025) 1940-2020 predictions used in the analysis can be found at DOI: 10.5281/zenodo.24324930

cyclone_tracking: scripts used in the running of CyTRACK and creation of cyclone database from CyTRACK output.
analysis: scripts used for the analysis of drylines and cyclones with relation to ENSO.
